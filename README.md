# BookNest

Digital Library web app to discover books via the Open Library API.

## Tech stack

- HTML5, CSS3, TypeScript (strict), Vite

## Setup

```bash
npm install
npm run dev      # http://localhost:5173
npm run build    # output in dist/
```

## Structure

```
├── index.html
├── package.json
├── tsconfig.json

```
